## Ce que vérifie le pipeline
le pipeline verifie que le code que l'on souhaite integrer a la base de code ne va pas casser l'ensemble
## Bénéfices pour l'équipe
l'equipe peu avoir un retour rapide d'une nouvelle integration de code et la branche main peut reste saine
## Bénéfices pour les parties prenantes
l'etat du code est visible de tous sous l'onglet actions et les livrables peuvent etre construis plus rapidement.
## Limites
un pipeline vert ne signifie pas toujour que tout est ok, l'image construite n'est pas lancé
